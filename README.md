# CoolCity v6｜路線功能開發版（非正式發布）

本版基於既有 v5 程式，新增可操作的「綠蔭路線」頁：起訖點選擇、地圖點選與拖曳、GPS 起點、向公開 OSM 步行路由服務取得實際路網路線，並顯示距離與估計時間。

**重要：這不是樹蔭推薦路線**。目前無逐路段遮蔭資料，不能聲稱路線較涼爽。公開路由服務可能有流量限制或暫時不可用，不適合直接當成正式商用基礎設施。預設地點座標僅為測試起訖點，正式發布前應確認位置精確度。

原 v5 的照片上傳仍使用 Firebase Storage，尚未接上 Google Drive；不要以本版公開收集照片。Firebase 權限與 Apps Script 驗證仍待整合測試。

測試：在此資料夾執行 `python -m http.server 8000`，以 http://localhost:8000/#walk 開啟。網路需能連接 OSM 底圖和路由服務。

下一步資料：可步行路網、逐路段樹蔭或樹冠資料、現場照片與觀察時間、重要目的地（校門/公車站/學校等），以及資料來源授權。
