# CoolCity 2.0 · v2.1.7

CoolCity 是碳吉 TanJi 的都市高溫調適、綠蔭地圖與民眾回報網站。

## 目前提供

- 會員：Google 與電子郵件註冊登入、密碼重設、自己的回報、管理員審核。
- 綠蔭回報：地圖選點、照片上傳、審核狀態管理。
- 綠蔭地圖：OSM 示範道路、經後端匿名化的已核准民眾觀察。
- 調適分析：已核准觀察的回報類別與遮蔭類別分布（最多 250 筆樣本，非官方統計）。
- 首頁氣溫：Open-Meteo 模式氣溫，可使用定位或縣市與行政區名稱查詢。行政區名稱解析依賴外部地理編碼 API。
- 小樹苗：登入後使用的 Firebase 雲端 AI 對話。
- 步行探索：北大特區路網示範，不代表已計算遮蔭最佳路線。

## 維護／部署提醒

本網站前端由 `index.html` + `assets/` 組成。公開已核准回報必須**另行部署** `asia-east1` 的 Firebase callable `listPublicReports`；未部署時地圖道路仍可使用，公開回報與統計會顯示提示。小樹苗 `chatWithSeedling` 為另一個函式，請不要因為新增公開回報函式而重新部署它。

請勿在 GitHub 保存服務帳戶私鑰、Gemini API Key 或 `.env`。Firestore 原始回報資料不對公開訪客開放；地圖以後端白名單欄位為準。

詳細發行、更新與安全注意請參考發行包附帶的 `README_部署與更新.md`。
