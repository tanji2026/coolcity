CoolCity v6 空白頁修復版（2026-10-24）

本版以先前 v6 整合開發版為基礎。修復：
1. 移除主程式不必要的外部模組依賴，降低整站空白風險。
2. 單一分頁渲染或初始化出錯時，顯示錯誤提示，不再讓其他分頁一起空白。
3. 主要 JavaScript 未成功載入時，首頁會顯示可理解的錯誤提示。
4. 加強手機 Safari 日期欄位及表單容器的寬度限制。
5. 地圖未成功載入時，定位按鈕不會因空地圖物件造成錯誤。

部署：
- 將 ZIP 解壓縮後，將 index.html 與整個 assets 資料夾原樣放到 coolcity GitHub Pages 儲存庫根目錄。
- 不要只上傳 index.html；保持 assets/css、assets/js、assets/data 子資料夾結構。
- 如果 GitHub Pages 是從 main 根目錄發布，確認 Settings > Pages 的來源正確。
- 重新整理時可使用無痕視窗，排除舊快取。

功能界線：
- 氣溫仍須設定安全的 API 代理端點；不會填入假的觀測數值。
- 民眾照片正式送出依然未完成安全整合，不可當成已啟用的公開回報服務。
- 步行路線需外部路線服務，無法保證服務可用，也不代表已計算樹蔭程度。
- 本版已通過 JS 語法與檔案路徑檢查，尚未在使用者的正式 GitHub Pages 實機驗證。
